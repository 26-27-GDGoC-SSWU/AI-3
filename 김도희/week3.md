## 군집
### k-평균
- 반복 몇 번으로 데이터셋을 빠르고 효율적으로 클러스터를 묶을 수 있는 간단한 알고리즘
- 군집에서 각 샘플의 레이블-> 알고리즘이 샘플에 할당한 클러스터의 인덱스
- 클러스터의 크기가 많이 다르면 잘 작동하지 않음 (샘플을 클러스터에 할당할 때 센트로이드까지 거리를 고려하는 것이 전부이기 때문)
- 하드 군집: 샘플을 하나의 클러스터에 할당
- 소프트 군집: 클러스터마다 샘플에 점수를 부여
#### k-평균 알고리즘
##### 가정
- 센트로이드가 주어질 경우:
  - 모든 데이터 샘플을 가장 가까운 중심점의 클러스터의 할당
  - 중심점은 클러스터에 포함된 샘플의 평균 위치로 계산함
- 센트로이드가 주어지지 않을 경우:
  - 랜덤으로 중심점 초기화
  - 예) 데이터셋에서 임의로 k개의 샘플을 뽑아 중심점으로 설정해준다.
 ##### 반복 과정
 - 첫 단계:
   1. 샘플을 가장 가까운 중심점의 클러스터에 할당(레이블 지정)
   2. 클러스터에 속한 샘플들의 평균을 계산하여 새로운 중심점을 업데이트
  - 반복:
    - 클러스터 할당->중심점 업데이트 과정을 반복
    - 중심점이 더 이상 변하지 않을 때까지 또는 정해진 반복 횟수에 도달할 때까지 수행
#### 센트로이드 초기화 방법
- 고정된 초기화:
  - 센트로이드 위치를 알고 있다면 직접 설정할 수 있게 됨
  -  예) init 매개변수에 센트로이드 배열을 지정하고, n_init=1로 설정하여 한 번만 실행
     ```python
     good_init=np.array([[-3,3],[-3,2],[-3,1],[-1,2],[0,2]])
     kmeans=KMeans(n_clustera=5, init=good_init, n_init=1, random_state=42)
     kmeans.fit(X)
     ```
- 랜덤 초기화
  - 랜덤한 방식으로 센트로이드를 초기화한 후 여러 번 알고리즘을 실행
  - n_init매개변수로 반복 횟수를 설정하며, 기본값은 10으로 되어 있음
  - 여러 번 실행 후 최적의 모델을 선정할 때는 각 샘플과 가장 가까운 센트로이드 사의 제곱 거리 합으로 이를 이너셔라고 부름
  - 가장 낮은 Interia 값을 가지고 있는 모델을 고르면 됨
- score() 메서드:
  - 사이킷런의 KMeans 클래스에는 모델의 성능을 평가하는 score() 메서드가 포함되어 있음
  - Interia 값을 음수로 반환함
- K-평균++ 초기화
  - 문제점: 랜덤 초기화로 인해 K-평균 알고리즘이 전역 최적해로 수렴할 가능성이 큼
  - 해결책: K-평균++알고리즘이 중심점 초기화를 개선하여 전역 최적해로 수렴할 가능성을 높임
  - 동작 원리:
    1. 데이터셋에서 랜덤으로 첫 번째 센트로이드 선택
    2. 나머지 센트로이드는 가장 가까운 기존 센트로이드까지의 거리 제곱에 비례한 확률로 선택
    3. k개의 센트로이드가 선택될 때까지 반복
  - 효과: 알고리즘 반복 횟수를 줄이고, 더 나은 초기화로 더 정확한 결과를 얻음
#### k-평균 속도 개선과 미니배치 k-평균
- k-평균 속도 개선
  - 엘칸: 삼각 부등식을 활용하여 k-평균 알고리즘의 속도를 높이는 방법을 제안.
  - 두 점 사이의 실제 거리를 계산하지 않아도 되는 경우를 찾아 계산량을 줄임
  - 각 센트로이드 간의 거리를 기반으로 샘츨-샌트로이드 간 거리 계산을 효율화
  - 장점: 클러스터가 많거나 데이터가 대규모일 때 속도 향상
  - 단점: 데이터와 클러스터의 특성에 따라 속도 향상이 제한될 수 있음
- 미니배치 평균
  - 데이터 전체를 사용하는 대신 작은 미니배치를 선택해 클러스터링을 수행
  - 일반 K-평균에 비해 속도 매우 빠름
  - 메모리에 들어가지 않는 대규모 데이터셋에도 적용 가능
  - 장점: 데이터셋이 클수록 성능 향상이 두드러짐, 메모리 제한 문제를 해결하며, 빠른 결과 제공
  - 단점: 일반 K-평균보다 Inertia 값이 다소 높음
#### 최적의 클러스터 개수 찾기
- 클러스터 수가 5보다 작거나 큰 값으로 설정된 경우-> 좋지 않은 모델이 만들어짐
- 실루엣 점수를 사용한 k 선택
  - 실루엣 점수는 클러스터링의 품질을 평가하는 지표
  - 한 데이터 포인트가 자신의 클러스터에 얼마나 잘 속했는지 나타냄
  - 점수는 -1에서 +1 사이값을 가짐
    - +1: 해당 샘플이 자신의 클러스터에 잘 속함
    - 0: 경계에 위치함
    - -1: 잘못된 클러스터에 속함
  - 실루엣 계수=(b-a)/max(a,b)
  - 평균 실루엣 점수: 모든 샘플의 실루엣 점수의 평균을 구해 최적의 k를 결정하면 됨

- 중심에서 가장 가까운 99% 샘플만 남겨 학습에 사용
### DBSCAN
#### 작동 방식
- ε-이웃
  - 각 데이터 포인트의 ε 반경 내에 몇 개의 다른 포인트가 포함되는지를 계산
  - 이 반경 내에 있는 점들의 집합을 ε-이웃이라고 부름
- 핵심 샘플
  - 이웃 내에 포함된 포인트 수가 최소 샘플 개수 이상인 경우, 해당 포인트를 핵심 샘플로 정의함
- 이웃 확장
  - 핵심 샘플의 ε-이웃에 있는 점들을 같은 클러스터로 확장함
  - 이 과정에서 새로운 핵심 샘플이 발견되면 이웃 확장을 반복하며 클러스터를 형성함
- 노이즈 판별
  - 핵심 샘플도 아니고 ε-이웃에 포함되지 않는 점들은 노이지(-1)로 분류
#### 주요 특징
- eps: ε 반경
- min_samples: 핵심 샘플로 정의되기 위한 최소 샘플 개수
- 레이블
  - labels_: 각 샘플의 클러스터 레이블을 저장함
  - 레이블 값이 -1인 샘플은 노이즈로 간주
#### 장점
 - 클러스터의 모양과 크기에 상관없이 밀집된 영역을 잘 탐지함
 - 노이즈와 이상치를 효과적으로 처리함
#### 한계
- 클러스터 간 밀집도가 너무 다를 경우, 적절한 파라미터 조합을 찾기 어려움
- 계산 복잡도가 O(m^2)으로 대규모 데이터셋에서 확장성이 제한됨
### 다른 군집 알고리즘
#### 병합 군집
- 방법: 각 데이터를 개별 클러스터로 시작한 뒤  가까운 두 클러스터를 반복적으로 병합
- 결과: 트리 형태로 시각화 가능
- 특징: 샘플 간 거리 행렬을 사용하며 대규모 데이터셋에는 비효율적
#### BIRCH
- 목적: 대규모 데이터셋을 처리할 때 효율적
- 방법: 데이터를 압축하여 트리 구조에 저장하고 클러스터링
- 장점: 제한된 메모리로 대량의 데이터셋 처리 가능
#### 평균 이동
- 방법: 데이터의 밀집도가 높은 방량으로 중심점 이동
- 특징: DBSCAN처럼 클러스터 수를 미리 설정할 필요 없음
- 단점: 계산 복잡도가 높아 대규모 데이터셋에 비적합
#### 유사도 전파
- 방법: 샘플 간 메세지를 교환하며 대표 샘플을 선택
- 특징: 클러스터 수를 미리 정하지 않음
- 단점: 계산 복잡도가 높고 대규모 데이터셋에 부적합
#### 스펙트럼 군집
- 방법: 샘플 간 유사도로 그래프를 생성하고 저차원 임베딩 후 군집화
- 특징: 복잡한 클러스터 구조에 적합
- 제약: 클러스터 크기가 매우 다르거나 데이터셋이 클 경우 성능 저하


# 10장. 케라스를 사용한 인공 신경망 소개
### 뉴런을 사용한 논리 연산
#### 인공 뉴런
- 하나 이상의 이진(on/off) 입력과 하나의 이진 출력을 가짐
- 입력이 일정 개수만큼 활성화 되었을 때 출력을 내보냄
- 매켤러와 피츠가 제한한 신경망 모델에서 비롯한 인공 뉴런
- 인공 뉴런의 네트워크를 만들어 논리 연산 수행 가능
### 퍼셉트론
#### 1. 퍼셉트론
   - 1957년, 프랑크 로젠블라트가 제안
   - 가장 간단한 인공 신경망 구조
   - 입출력이 이진값(on/off)이 아닌 어떤 숫자이고, 각ㄱ각의 입력 연결은 가중치와 연관 되어있음
   - TLU 또는 LTU라 불리는 인공 뉴런 기반
#### 2. TLU
   - 입력이ㅡ 선형 함수를 계산->결과에 계단 함수 적용
   - 모델 파라미터: 입력 가중치(w), 편향(b)
   - 헤비사이즈 계단 함수: 퍼셉트론에서 가장 널리 사용되는 계산 함수
   - 간단한 선형 이진 분류 문제에 사용될 수 있음
     - 입력의 선형 함수 계산 -> 결과 > 임곗값 -> 양성 클래스 출력
     - 입력의 선형 함수 계산 -> 결과 < 임곗값 -> 음성 클래스 출력
   - 하나의 층 안에 놓인 하나 이상의 TLU로 구성되고, 각각의 TLU는 모든 입력에 연결됨-> 완전 연결 층(밀집 층)
   - 입력은 입력을 구성하고, TLU의 층을 입력층이라고 함
   - 퍼셉트론의 훈련(헤브의 규칙)
     - 헤브의 규칙: 두 뉴런이 동시에 활성화 될 때마다 이들 사이의 연결 가중치는 증가함(생물학적 뉴런이 다른 뉴런을 활성화시킬 때 이 두 뉴런의 연결은 더 강해짐
     - 네트워크가 예측할 때 만드는 오차를 반영하도록 헤브의 규칙을 변형하여 훈련(오차가 감소되도록 연결 강화, 잘못된 예측을 하는 모든 출력 뉴런에 대해 올바를 예측을 만들 수 있도록 입력에 연결된 가중치 강화)
     - 한 번에 안 개의 샘플 주입->각 샘플에 대한 예측 생성
    - 퍼셉트론 수렴 이론
      - 훈련 샘플이 선형적으로 구분될 수 있다면 해당 알고리즘은 정답에 수렴
      - 퍼셉트론 학습 알고리즘은 확률적 경사 하강법과 유사
    - 퍼셉트론의 약점과 보완
      - 약점: 일부 간단한 문제를 풀 수 없음. 실용적인 애플리케이션 부족
      - 보완: 퍼셉트론을 여러 개 쌓아올려 제약 줄이기->다층 퍼셉트론(MLP)
### 다층 퍼셉트론과 역전파
#### 1. 다층 퍼셉트론의 구조
- 입력 층 하나, 은닉층이라 불리는 하나 이상의 TLU층, 출력층
- 하위층(입력층과 가장 가까운 층), 상위 층(출력에 가까운 층)
#### 2. 심층 신경망(DNN)
- 은닉 층을 여러 개 쌓아 올린 인공 신경망
#### 3. 역전파
- 후진 모드 자동 미분
  - 모든 그레이디언트를 자동으로 효율적으로 계산하는 기번
  - 네트워크를 두 번만 통과(전진, 후진)하면 모든 단일 모델 파라미터에 대한 신경망 오차의 그레이디언트를 계산할 수 있음
- 역전파
  - 후진 모드 자동 미분 실행
  - 그레이디언트를 이용하여 경사 하강법 다녜 수행
  - 두 과정 반복
  - 신경망의 오차 감소
  - 최솟값에 도달
  =>후진 모드 자동 미분과 경사 하강법을 결합한 것을 역전파라고 함
  - 신경망과 모든 종류의 계싼 그래프에 적용 가능
- 역전파의 작동 방식
  1. 정방향 계산: 역전파 알고리즘의 미니배치에 대한 예측 만들기 -> 오차 측정
  2. 역방향 계산: 역방향으로 각 층을 거치면서 각 연결이 오차에 기여한 정도를 측정
  3. 경사 하강법: 오차가 감소하도록 가중치와 편향 조정
### 회귀를 위한 다층 퍼셉트론
1. 퍼셉트론은 회귀 작업에 사용될 수 있음
2. 하나의 값 예측에는 하나의 출력 뉴런만 필요
3. 다변량 회귀(동시에 여러값 예측)에서, 하나의 출력 차원마다 하나의 출력 뉴런이 필요
4. 후버 손실: 평균 제곱 오차와 평균 절대 오차를 조합한 것
   - 오차>임곗값: 선형 함수, 평균 제곱 오차보다 이상치에 덜 민감
   - 오차<임곗갑: 이차 함수, 평균 절대 오차보다 더 빠르고 정확하게 수렴
